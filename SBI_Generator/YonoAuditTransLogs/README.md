# Kafka Message Generator for YONO Audit Logs

A high-performance Go-based Kafka message generator that produces configurable YONO audit messages (`yono_adt_error` and `yono_adt_trans`) with precise throughput control, comprehensive monitoring, and flexible configuration.

## Features

- **Configurable Message Generation**: Generate error-only, transaction-only, or combined messages based on distribution percentages
- **Precise Throughput Control**: Token bucket rate limiting for accurate EPS (Events Per Second) targeting
- **High Concurrency**: Worker pool pattern with configurable pool size and producer pool
- **Session Management**: Automatic session ID rotation with configurable intervals
- **Comprehensive Monitoring**: Prometheus metrics and structured logging
- **Flexible Configuration**: YAML-based configuration with validation
- **Graceful Shutdown**: Signal handling with proper resource cleanup

## Configuration

The application uses a YAML configuration file. See `config/config.yaml` for the default configuration.

### Key Configuration Sections

#### Execution Control
```yaml
execution:
  mode: "duration"      # "duration" or "count"
  duration: "5m"        # How long to run
  count: 10000          # Number of messages (if mode=count)
  eps: 1000             # Target events per second
```

#### Message Distribution
```yaml
distribution:
  error_only_percent: 0   # % messages with only error
  trans_only_percent: 70  # % messages with only transaction
  both_percent: 30        # % messages with both
```

#### Kafka Configuration
```yaml
kafka:
  brokers:
    - "localhost:9092"
  topic: "yono-audit-messages"
  producer:
    num_producers: 10
    required_acks: 1
    compression: "snappy"
```

#### Concurrency
```yaml
concurrency:
  worker_pool_size: 100
  buffer_size: 1000
  rate_limiter_burst: 100
```

See the [PRD](PRD.md) for complete configuration documentation.

## Monitoring

### Prometheus Metrics

Metrics are exposed on port 9090 (configurable) at `/metrics`:

```bash
curl http://localhost:9090/metrics
```

Available metrics:
- `kafka_messages_generated_total{type="error|trans|both"}` - Total messages generated by type
- `kafka_messages_sent_total` - Total messages sent to Kafka
- `kafka_messages_failed_total` - Total failed messages
- `kafka_current_eps` - Current events per second
- `kafka_message_generation_duration_seconds` - Message generation latency histogram

### Logs

The application uses structured logging (JSON or text format). Metrics are logged at configurable intervals:

### Components

- **Message Generator**: Creates YONO audit messages with proper field population

## Troubleshooting

### Kafka Connection Issues

If you see connection errors:
1. Verify Kafka brokers are accessible: `telnet localhost 9092`
2. Check broker addresses in config file
3. Ensure topic exists or auto-creation is enabled

### Low Throughput

If actual EPS is lower than target:
1. Increase `worker_pool_size`
2. Increase `num_producers`
3. Reduce `required_acks` (0 for no acknowledgment)
4. Use faster compression (snappy or none)

### High Memory Usage

If memory usage is high:
1. Reduce `buffer_size`
2. Reduce `worker_pool_size`
3. Reduce `num_producers`

## Performance Tuning

For optimal performance:

- **High Throughput (10K+ EPS)**:
  - `worker_pool_size: 200+`
  - `num_producers: 20+`
  - `compression: "snappy"`
  - `required_acks: 1`

- **Low Latency**:
  - `required_acks: 0`
  - `compression: "none"`
  - `flush_frequency: "10ms"`

- **Reliability**:
  - `required_acks: -1` (all replicas)
  - `idempotent: true`
  - `retry_max: 5`
